Undergraduate Thesis 2026

Real-Time PPE Violation Detection

Undergraduate thesis project for the Informatics program at Gunadarma University.

From a camera feed to an actionable alert. This project connects PPE detection with a monitoring interface, Telegram notifications, and a physical buzzer.

The challenge

Detect PPE violations in a live camera stream and turn those detections into visible and audible alerts.

What I built

A YOLOv11m detection pipeline with a Streamlit interface, RTSP camera input, and ESP32 alert integration.

Camera feed→PPE detection→Telegram + buzzer
PythonYOLOv11mONNXStreamlitESP32
Results & technical details +

Developed as my undergraduate thesis. The model detects Helmet, Mask, Person, and Vest, and was trained using 4,410 images.

93.0%Test precision
85.9%Test recall
91.8%Test mAP@0.5

Test-set mAP@0.5:0.95: 65.8%. These metrics describe model evaluation, not field deployment performance.

  • Used ONNX inference to process IP camera input over RTSP in Streamlit.
  • Connected Telegram Bot image notifications and an ESP32-controlled buzzer to detected PPE violations.

Freelance IoT Project 2026

Fingerprint Attendance & Door Access

Freelance IoT project for attendance recording and classroom access control.

One fingerprint interaction for classroom access and attendance recording, connecting a physical door mechanism with a database.

The challenge

Connect user verification, classroom door access, and attendance records within one system.

What I built

An ESP32 system that verifies fingerprints, activates a relay-controlled solenoid lock, and records attendance in MySQL.

Scan fingerprint→Verify user→Unlock + record
ESP32Fingerprint sensorRelay & solenoidMySQL
Build details +

Developed as a freelance IoT project. My contribution covered sensor and lock integration, attendance database integration, and hardware-software testing and troubleshooting.

  • Successful fingerprint verification triggers automatic door unlocking.
  • Attendance records are integrated with a MySQL database.
